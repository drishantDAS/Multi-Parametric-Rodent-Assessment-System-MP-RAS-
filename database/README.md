# Database

This directory contains the database schema, table definitions, queries, and database-related documentation for the MP-RAS system.

## Database Technology

- PostgreSQL

## Purpose

The database is used to store structured experimental data generated by the MP-RAS system.

## Data Categories

The database may contain:

- Experimental session information
- Rodent/sample identification
- Weight-distribution measurements
- Gait-analysis results
- Paw-swelling measurements
- Timestamps
- Experimental metadata

## Data Flow

```text
MP-RAS Hardware
      ↓
Analysis Software
      ↓
Flask Backend
      ↓
PostgreSQL Database
      ↓
Experimental Results
