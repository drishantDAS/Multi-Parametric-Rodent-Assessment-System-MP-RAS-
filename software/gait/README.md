# Gait Analysis Software

This directory contains the software components used for camera-based rodent gait analysis in the MP-RAS system.

## Purpose

The gait analysis software processes camera data to detect and analyze paw movement during rodent locomotion.

```text
Camera Input
     ↓
Image Acquisition
     ↓
Pre-processing
     ↓
Paw Detection
     ↓
Paw Tracking
     ↓
Gait Parameter Extraction
     ↓
Results
