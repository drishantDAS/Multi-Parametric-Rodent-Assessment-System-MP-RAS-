# Paw Swelling Analysis Software

This directory contains the software components used for camera-based paw swelling analysis in the MP-RAS system.

## Purpose

The software processes paw images captured using the Raspberry Pi camera and extracts measurable information for objective swelling assessment.

## Processing Pipeline

```text
Paw Image
    ↓
Image Acquisition
    ↓
Image Pre-processing
    ↓
Region of Interest Selection
    ↓
Paw Detection
    ↓
Measurement Extraction
    ↓
Swelling Analysis
    ↓
Results
